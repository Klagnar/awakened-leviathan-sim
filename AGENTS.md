# AGENTS.md

## Rules
- Use Node 22. After any `npm ci`, rerun `scripts/install-beta-sdk.sh` (it builds the pinned osrs-sdk beta into `node_modules`).
- Follow the osrs-sdk patterns: `Mob` subclasses for the boss and the pathfinder, `Entity` subclasses for debris and floor effects, a `Region` subclass for the arena.
- Keep every boss number in `src/content/leviathan/data.ts` as a `Fact` with a trust level (`confirmed`, `inferred`, `unverified`) and a source.
- Never commit extracted cache assets or models. `public/osrs-assets/` is generated by `npm run assets`.
- Keep the project free: no ads, donations or paid features. Keep the Jagex credit line in the README and the app. Keep "RuneScape" and "Jagex" out of names.
- Prove a change with `npm run typecheck`, `npm test` and a look at `npm start` before calling it done.

## TypeScript
- These rules apply to new and changed code in `src/`. Test doubles in `test/` may cast at the jsdom boundary.
- No `any`. No `as` casts or non-null `!` to silence the compiler.
- Model outcomes and run states as discriminated unions, and end each `switch` over them with a `never` check.
- Brand primitives that are easy to mix up, such as ticks.
- Keep timing data `readonly`.
- Do not declare a field optional when it is always set in practice.
- Tiles are SDK coordinates: x east, y south. Region tile (x, y) is SDK tile (x, 63 - y).
